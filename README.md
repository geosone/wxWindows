# wxWindows 1.68E for OpenWatcom

wxWindows 1.68E (1996, Julian Smart, AIAI, University of Edinburgh), the
last wxWindows with Windows 3.1 support, built for **16-bit Windows
(Windows 3.1x, Windows 9x) with OpenWatcom on Linux**.

The first commit is the unchanged original (wx168_1.tgz); everything after
it is the OpenWatcom port.  Used by [Open 386MAX](https://github.com/geosone/386MAX)
for its Windows programs.
